# charts

Chart components (bar, line, donut, and later more). Each chart gives every mark a stable key, describes it with `MarkGeometry`, and emits `enter`, `update`, `exit`, `hover` and `leave` events. Charts import only from core and never name a specific effect: the composition root (`src/index.ts`) hands them the preset and icon registries as a `ChartEnv`.

| File | What it holds |
| --- | --- |
| `bar.ts` | `barChart`: its marks, ticks and focus ring in the DOM, staged and interruptible updates (`retarget`), and what the table, legend and announcements say; the rest is in `shell/` |
| `shell/` | What charts share beyond their marks, built from callbacks rather than a base class: mark events (`events.ts`), one hover for pointer, touch and keyboard focus, which `leave()` ends (`hover.ts`), transitions and the runner's order for an update (`transitions.ts`), leaving marks (`leaving.ts`), DOM order that keeps focus (`order.ts`), the container's width, web fonts and the hover duration (`watch.ts`), the labels a chart's `labels()` reports (`labels.ts`), and `ChartEnv`, the container, the accessible name and the `needs` check (`setup.ts`) and the default `format` (`format.ts`) |
| `bar-layout.ts` | The bar chart's layout, pure: encoding, sorting, the nice scale, the frame (scale and bands), which labels are drawn so none overlap, and `placeRow` / `placeTick`, which draw a laid-out row or any state in between |
| `donut.ts` | `donutChart`: its slices, outside labels, centre text and focus ring in the DOM, staged updates (the values, then the slices turning to their new places), and what the table (each share, a total row), legend and announcements say |
| `donut-layout.ts` | The donut's layout, pure: encoding, sorting, the frame (its size, the ring's centre and radii, from the room its labels leave), the slices laid end to end from their values, and `placeSlices` / `placeSlice` / `placeLabels` / `placeCenter`, which draw any state in between (`placeSlices` gives each slice its neighbours' labels) |
| `line.ts` | `lineChart`: its lines, points, x columns (the focus stops), crosshair, end labels and ticks in the DOM, on a number or a time axis, gaps where a value is missing, `reveal`, a curve that eases in and out, and staged updates in which rows grow out of and fold into their neighbours |
| `line-layout.ts` | The line chart's layout, pure: encoding (an x of numbers or of `Date`s, and the curve), the frame (value scale and plot box), and `placeLines` / `placePoints` / `placeColumns` / `placeEndLabels`, which draw any state of the rows at any reveal, breaking a line at a missing value and bending it between rows when it's curved; and `loneValues`, the points that show at rest |
| `curve.ts` | A line's curve, pure: d3's `curveMonotoneX` in the data's units, each piece flattened within 0.1 px through the chart's scales, eased from straight, and bending only as much as a row coming or going shows |
| `time.ts` | A time axis, pure and with no dependency: the step between ticks, from seconds to years, ticks on boundaries in UTC or local time, a calendar month on (`monthsOn`, for Page Up and Page Down), and how a time is worded, through `Intl.DateTimeFormat` |
| `types.ts` | What charts share: options, `MarkEvent(s)`, `Chart`, accessors |
| `colors.ts` | `colorAssignment`: palette slots that follow the entity |
| `series.ts` | `seriesLabels`: a series' name for people, and checking the option |
| `motion.ts` | A chart's motion from its `motion` option |
| `keyboard.ts` | Keyboard focus, shared by the charts and `expressive()`: the roving tabindex, arrow keys (or where a chart says they go, as a line chart's points do), Page Up and Page Down, Home, End and Escape, whether focus followed a key press, and where focus goes when its mark leaves, its element is replaced or the marks change kind |
| `interaction.ts` | Pointer and touch hover, delegated from the `<svg>`; a target that isn't an element (a line chart's nearest point) is found from where the pointer is |
| `tooltip.ts`, `legend.ts` | The tooltip beside the hovered or focused mark, and the series legend |
| `table.ts` | The data table: its contents from the chart's rows (`tableModel`, pure), with its headers (`table.series` heads each series' column, else its `seriesLabels` name), and the `<details>` or visually hidden table that shows them, kept by key |
| `announce.ts` | With `announce`, the polite live region and the chart's summary of an update |
| `switch.ts` | `chartSwitch`: views of the same data in one grid cell, one shown at a time, and a switch that plays a transition effect on each pair of marks with the same key in an overlay, moves the labels, fades unmatched marks and the views' other parts, reverses mid-way, and moves focus and announces the new view; in a `link()`, its view on show takes part |
| `controls/` | On-page controls the viewer operates: `motionSwitch` (`motion-switch.ts`), the viewer's choice of motion mode, and `playButton` (`play-button.ts`), the Play/Pause button for a `playback()` |
| `adapter/` | `expressive()`: effects on SVG marks drawn by other code. Reading the source (`source.ts`), coordinates through CTMs (`space.ts`), bars from rects (`bars.ts`), points and shapes from circles and other shape elements (`expressive.ts`), slices from a ring's paths (`slice.ts`), the host-mark style handle (`host-style.ts`), the record of every change to the host's DOM, so `destroy()` can undo it (`edits.ts`), `watch`, which hears the host's own attribute changes and hands them on once a frame (`watch.ts`), and `fromVegaView()`, which reads a Vega or Vega-Lite View's marks from its scenegraph and follows its renders (`vega.ts`) |
| `render/` | The drawing API in SVG: `svgSurface` (the runner's surface), `svgLayer`, `svgMarkHandle`; focus rings and halos masked to outside a mark, for marks that touch (`outside.ts`); theme tokens and the shared stylesheet; text measurement |
