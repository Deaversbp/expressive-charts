The motion rules behind this page

  • Hover feedback is a 100 ms color shift with the other marks dimmed. Nothing moves under the cursor.
  • Presentation mode stages data changes at about one second: values first, then positions.
  • Analysis mode caps every transition near 200 ms with no staging, so exploring stays fast.
  • Off removes all motion. It is the default when your device asks for reduced motion.
  • Every mark keeps a stable identity through sorts, updates and morphs. That identity is what makes the motion readable.
